# 团队账号

团队账号是由管理员授予的站点角色，用于在一个工作台管理多个平台账号。同一平台可添加多个绑定，智慧树、超星、U校园及其他模块共用一个总配额。它不包含成员邀请、子用户登录或团队内权限分级。

## 管理员设置

1. 打开「站点管理 → 用户管理」，创建用户时选择「团队账号」，填写跨平台账号总上限。
2. 也可在已有用户的「角色」中选择「团队账号」。原有连接自动登记，登录态及任务继续保留。
3. 点击该用户的「平台账号上限」，调整 0–1000 的总上限；默认 10。列表显示已使用数量。

降低上限不会删除已有绑定或停止任务。当前用量达到或超过上限时禁止新增；设置为 0 可冻结新增。并发添加和正在登录的账号位也受服务端事务配额限制。

角色改回成员或管理员前，需移除团队新增的绑定；升级前原有的默认连接可保留。团队角色没有管理员权限，公开注册和邀请码注册均只创建普通成员。

## 团队使用

1. 在「平台连接」选择平台并添加账号位，备注用于区分成员，例如「张同学 · 本学期」。
2. 选择扫码或密码登录，完成该账号位的连接。登录未完成也会占用一个名额，可移除闲置账号位释放配额。
3. 点击对应账号的「查看课程」。课程卡片、目录及链接保留所选绑定；每个平台显示当前选择账号的课程，可回到「平台连接」切换。
4. 在课程中创建学习、问答或其他任务。任务固定使用创建时的账号，切换页面选择不会更换任务账号。任务列表和日志显示账号备注。

「断开登录」撤销该绑定的登录态并暂停其运行和排队任务，账号位仍保留。重新连接原账号后可继续原任务；如果改登另一个平台身份，旧任务不会自动套用新身份。

「移除绑定」停止该绑定的未结束任务、撤销登录态并释放名额；任务历史和平台学习记录保留。移除后重新添加会创建新的绑定，原任务不转移到新绑定。平台模块停用或卸载后，仍可在「平台连接」移除遗留绑定。

团队共用站点登录、模型、夜间暂停偏好及并发任务策略。平台 Cookie、模块状态、浏览器页面及课程缓存按具体绑定隔离。题库中的平台已确认答案归站点用户，供该团队的任务复用；其他站点用户不能读取团队凭据或题图。

## 升级和回退

Framework 0.1.12 与 WebUI 0.1.3 配套提供团队管理界面，HTTP 和模块协议仍为 v1，无需修改平台模块。

数据库自动从版本 3 升级到版本 4，增加 `users.platform_account_limit`、`platform_accounts` 及 `tasks.account_id`。已有用户默认仍是原角色，原任务的绑定字段为 `null`，继续指向原有默认连接；已有密文及主密钥无需重新加密。

升级前停止后端并备份数据库、主密钥及模块目录。回退到只支持旧数据库版本的后端时，必须同时恢复升级前的数据库备份；仅切换代码无法降级数据库。

接口详情见 [Web API](WEB-API.md)。测试使用模拟模块和合成账号，不需要真实平台账号。
